# NI_Project
Neuroinformatics project 24/2025

## Project Contents

- `x.npy` and `y.npy`: Neural data and class labels
- `Final_project_AT.ipynb`: The main notebook with all steps, visualizations, analysis, and results
- `requirements.yaml`: Conda environment file with required packages
- `slides.pdf`: Project summary presentation
- `README.md`: Instructions and project overview

To get this code running follow the steps below:

#### 1. Clone the repository to your machine.  

#### 2. unzip the file.  

#### 3. If you are using conda to manage you virtual environments run the following in a terminal open at the repository level "NI_Project".
```bash
conda env create -f requirements.yaml
```

#### 4. Ensure that 'x.npy' and 'y.npy' are placed in the NI_Project\data directory of the notebook, the data is not included in this repo.

#### 5. lauch jupyter notebook at repo location "NI_Project" by opening a terminal and cd into the NI_Project repo then:
```bash
jupyter notebook
```
